升舱通道地图

几扇门，没有一扇写着「保证」。航司想要的是：你多飞、多刷、多付钱。

通道 01 / 06 · 里程

里程池 / 归集

  1. 升舱常要同一计划里有足够里程——散落五家等于五份不够用
  2. 联盟互通：飞 A 存 B，再拿 B 的里程去申请升舱（规则、比例各家不同）
  3. 先想清楚「我最常飞哪条线、哪家厅/升舱最香」，再决定主积哪家
  4. 坑过期、合作终止、动态定价——里程不是存款

通道 02 / 06 · 卡点

信用卡积分 → 升舱燃料

  1. 银行积分可转航司里程，或兑升舱相关权益——看当期合作表
  2. 开卡奖励、消费倍数、转点比例：同一张卡，今年和明年可能完全两样
  3. 思路大额消费前先问：这笔刷哪张，转哪家里程最划算
  4. 别为了点去硬消费；算完「点的价值」再动卡

通道 03 / 06 · 市场

闲鱼 / 代理：有人在卖「捷径」

  1. 市场上能看到：便宜票、升舱名额、状态匹配代办、各类「包过」话术
  2. 风险账号、证件、支付纠纷、政策一变全废——自己甄别，别轻信包票
  3. 真要碰：小额试水、留证据、默认可能失败
  4. 合法合规边界因地区而异；公司差旅单另说

通道 04 / 06 · 促销舱

促销舱位：有时比「升」更香

  1. 官网闪促、商务舱 / PE 打折、错误价（少见且易取消）——直接买到位
  2. 「经济舱 + 赌升舱」vs「咬牙买促销商务」：算总价和确定性
  3. 关注航司 App 推送、邮件、常旅客日——窗口往往很短
  4. 经验淡季、新开航线、红眼班，促销密度更高

通道 05 / 06 · PE

超级经济舱 · 经常是甜点

  1. 不必一口吃成商务：PE 空间、餐食、登机次序往往已经舒服一截
  2. 有身份时，某些航线 PE 门槛更友好——或用里程补差升到 PE
  3. 故事国泰 PEK–HKG：有 Emerald 级身份时，超级经济舱体感已经够用
  4. 长途再考虑要不要继续追商务；短段 PE 性价比常胜

通道 06 / 06 · 匹配

状态匹配 · Status match

  1. 拿着 A 航司的精英身份，去申请 B 航司对等或接近的等级（活动制）
  2. 常见窗口：航司抢人、新开计划、信用卡联名、并购过渡期
  3. 匹配到手往往是试用期——还要在时限内飞够才保级
  4. 变规则、材料、是否开放，几乎年年不同；看到就收藏，别背死
